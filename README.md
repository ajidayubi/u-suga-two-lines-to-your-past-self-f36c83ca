Two lines to your past self: one warning about a single moment, one sentence on why it mattered and what changed because of it. Free to enter, judged blind pairwise by an AI judge on how concrete the moment is and how clearly the second line traces cause and effect, with the best-ranked warning taking the reward.

## Run it

```sh
python3 main.py
```
